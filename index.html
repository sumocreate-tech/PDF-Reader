使い方・メモ
  • 対応形式: WebP / JPG / PNG / GIF / AVIF / BMP / SVG / PDF
  • フォルダを選ぶと、サブフォルダも含めて 1, 2, 10 の自然順で並べて開きます。
  • フォルダ選択が使えない端末（iOS 18.3 以前など）では、「ファイルを選ぶ」でフォルダ内を全選択するか、ドラッグ＆ドロップを使ってください。
  • 日本語のPDFを初めて開くときだけ、文字データ（cMap）を取得するためネット接続が必要です。一度開けば以降はオフラインでも表示できます。
  • 操作: 左右タップでページ送り、中央タップでメニュー、左右スワイプも使えます。
  • 拡大: 2本指でピンチ、拡大中は1本指で移動できます（ページを送ると元に戻ります）。メニューの「拡大ロック」で拡大を無効にできます。
  • 履歴: 最近開いたPDFを5件まで端末内に保存し、前回のページから続きを開けます（150MBを超えるPDFは保存しません）。
  • オフライン: 初回だけネットに繋いで開けば、以降は機内モードでも起動できます。ファイルはどこにも送信されません。
